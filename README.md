# QuickChat Homebrew tap

QuickChat, Option+Space ile açılan bağımsız bir macOS sohbet penceresidir.

## Kurulum

macOS 13 veya üzeri gerekir. Intel ve Apple Silicon desteklenir.

```sh
brew install --cask frknakbl/tap/quickchat
```

Ardından Uygulamalar klasöründen QuickChat’i açın.

Bu önizleme Apple tarafından noter onaylı değildir; macOS ilk açılışı engelleyebilir.
Açmadan önce [yayın ve kurulum notlarını](https://github.com/frknakbl/quickchat-app) okuyun.

## Güncelleme

```sh
brew update
brew upgrade --cask frknakbl/tap/quickchat
```

## Kaldırma

```sh
brew uninstall --cask frknakbl/tap/quickchat
```

Normal kaldırma sohbet oturumunu ve uygulama tercihlerini silmez.
